# RELEASE v0.4.0: Traces

**Status:** planned
**Design choices (ARCH 06):** D1
**Exit gate:** one row per trace; waterfall, flame graph and span panel data correct on seeded traces; log pivot works both ways
**Depends on:** 0.3
**Requirements:** R-R1 R-R2 R-R3 R-R4 R-R5 R-R6

## Scope

- Trace list with histogram and latency scatter
- Trace detail: waterfall, flame graph, span panel
- Trace ↔ logs pivot

## Acceptance criteria

| AC | Reqs | Statement | Tests (≥2 each) |
|---|---|---|---|
| AC0.4.1 | R-R1 | List returns one row per trace with duration, span/service/error counts, root service and operation; `service`, `min_ms`, `errors` and conditions filter it | `ac_0_4_1_list_shape`, `ac_0_4_1_filters_bound`, `ac_0_4_1_one_row_per_trace_live` |
| AC0.4.2 | R-R2 | Histogram and scatter points share the filters; points are capped | `ac_0_4_2_histogram_matches_filters`, `ac_0_4_2_scatter_capped` |
| AC0.4.3 | R-R3 | Detail takes a validated hex `trace_id`; non-hex is 400; spans ordered by start; waterfall rows carry depth and offset | `ac_0_4_3_trace_id_validated`, `ac_0_4_3_spans_ordered`, `ac_0_4_3_waterfall_depth_offsets`, `ac_0_4_3_detail_live` |
| AC0.4.4 | R-R4 | Flame graph layout merges identical call paths with correct self and total time | `ac_0_4_4_flame_merges_paths`, `ac_0_4_4_flame_self_total_times` |
| AC0.4.5 | R-R5 | Span panel returns attributes (flat `span_attributes.*` columns), resource attributes, events and links | `ac_0_4_5_span_attributes_flat_columns`, `ac_0_4_5_span_events_links` |
| AC0.4.6 | R-R6 | Logs by `trace_id`/`span_id`; each log row exposes its trace link; trace detail embeds its logs | `ac_0_4_6_logs_by_trace`, `ac_0_4_6_log_rows_link_trace`, `ac_0_4_6_trace_logs_live` |

## Notes

Schema finding (live, v1.2.1): span attributes are flat columns named `span_attributes.<key>`; log and resource attributes are JSON.
