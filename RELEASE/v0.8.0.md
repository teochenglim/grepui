# RELEASE v0.8.0: Dashboards

**Status:** planned
**Design choices (ARCH 06):** D1 D4
**Exit gate:** build, save, reload and share a dashboard with every panel type on seeded data
**Depends on:** 0.7
**Requirements:** R-B1 R-B2 R-B3 R-B4 R-B5 R-B6

## Scope

- Folders, dashboards, tabs
- All panel types except Custom Charts (arbitrary user JS is excluded on purpose)
- Variables, filters, time range, auto refresh, compare-with-past
- JSON import/export, move; public links; TV mode and playlists

## Notes

Custom Charts are excluded: they would execute arbitrary JavaScript. The HTML panel is the safe subset.
