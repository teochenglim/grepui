## Notes

A dashboard is one JSON document (tabs, panels, variables, default range and refresh) validated into a canonical form (`dash::canonical`) that is stored, exported and returned, so export then import is an identity and ids stay stable. Panels run their stored query on the server (`GET /dashboards/{id}/panels/{panel}/data`); the browser never sends SQL, a public link reaches only those queries, and a public view omits the query text (ADR 0009). SQL panels use the SQL-mode parser allowlist, PromQL panels the v0.6.0 checker. Variables: `query` ones list the first column of their query (capped at 200), `custom` ones their values; in SQL `$name` becomes `?` (several for multi-select, `NULL` for an empty one) outside strings, quoted names and comments; PromQL values are limited to letters, digits and `_ . : / -`; a multi-select with nothing chosen means all in the page.

Panel types: line, area, stacked area, vertical and horizontal bars (plain and stacked), scatter, pie, donut, heatmap, stat, gauge, table (with pivot mode and totals), geo map, sankey, markdown, HTML. Each declares the column shape it needs; a result that does not fit is reported on the panel, not as a failure. PromQL results become `[time, series, value]` rows for time-based types and the last value per series for the rest. Markdown and HTML are rendered and sanitised on the server and shown in a script-less sandboxed frame. The geo map draws points on a plain latitude/longitude grid (no outside tiles). Custom Charts are excluded on purpose.

Time: refresh options are off, 5 s, 10 s, 30 s, 1 m, 5 m, 15 m, 1 h (floor 5 s, enforced when a spec is saved and in the page); compare-with-past (1 h, 1 d, 7 d or the previous period) runs the same query on the shifted window and moves the time column forward so it overlays; only time-series types (line, area, stacked area, scatter) compare. Public links: random 128-bit token, only its SHA-256 stored, expiry 1 hour to 90 days, revocable, 410 when expired and 404 when unknown or revoked; there is no login yet, so this matters from v0.11.0. Playlists rotate by the clock (`now / interval` modulo the list), so all displays agree; TV mode hides the chrome (`?tv=1`).

State: schema version 3 adds `grepui_folders`, `grepui_dashboards` (also holds playlists, `kind`) and `grepui_shares`; run `grepui migrate`. The playground now adds a Demo overview dashboard (all panel types) to an empty store. Deleting a folder deletes its dashboards (soft deletes). Verified live on a fresh v1.3.0: save and reload a dashboard in the real state store, variable options from data, exact panel numbers with a multi-select bound as parameters, hostile values as plain values, pie and line shapes, compare, public link, cascade delete, export and import. Checked in a browser: list, the demo dashboard on all three chart tabs, Notes (sandboxed frames), edit and save, public view, playlist display. Not exercised in a browser: folder and bulk move controls, import box, Export buttons, TV mode through the link, revoke button. Known gap: no panel drag and resize (width and height are numbers), no Grafana import.
