# RELEASE v0.2.0: Logs

**Status:** planned
**Design choices (ARCH 06):** D1 D4 D6
**Exit gate:** filter bar → bound SQL; SQL mode refuses non-read statements; live tests on seeded OTLP logs
**Depends on:** 0.1
**Requirements:** R-L1 R-L2 R-L3 R-L4 R-L5 R-L6 R-L7 R-Q1

## Scope

- Logs page: query bar, histogram, results table, expandable rows
- Fields sidebar with types, quick mode, top values
- Source details and Search Around
- SQL mode (parser-validated), CSV/NDJSON export
