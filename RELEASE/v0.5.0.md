# RELEASE v0.5.0: Services and service map

**Status:** planned
**Design choices (ARCH 06):** D1
**Exit gate:** RED matches numbers computed from the seed; service map and catalog render from API data
**Depends on:** 0.4
**Requirements:** R-V1 R-V2 R-V3 R-V4

## Scope

- Services list with RED
- Per-service series and operations
- Dependencies and service map graph
- Service catalog with annotations (metadata table)

## Acceptance criteria

| AC | Reqs | Statement | Tests (≥2 each) |
|---|---|---|---|
| AC0.5.1 | R-V1 | Per service: requests, rate, error %, avg, p95 over server/consumer spans; matches seed | `ac_0_5_1_red_shape`, `ac_0_5_1_red_matches_seed_live` |
| AC0.5.2 | R-V2 | Series per bucket and operations breakdown; bucket from a fixed set | `ac_0_5_2_series_bucketed`, `ac_0_5_2_operations_breakdown` |
| AC0.5.3 | R-V3 | Dependencies from parent/child spans across services with calls and errors; graph layout has nodes, edges, no self loops by default | `ac_0_5_3_dependency_query_shape`, `ac_0_5_3_graph_nodes_edges`, `ac_0_5_3_dependencies_live` |
| AC0.5.4 | R-V4 | Catalog lists every service with first/last seen and RED summary; annotations persist and are audited-ready | `ac_0_5_4_catalog_lists_services`, `ac_0_5_4_annotations_roundtrip` |

## Notes

No joins (ADR 0007): dependency edges (caller to callee) must not use a self-join, which returns wrong rows on GreptimeDB v1.2.1; fetch spans with a plain scan and pair parents and children in Rust, or use conditional aggregation.
