# RELEASE v0.12.0: Query management, work groups and federation

**Status:** ready
**Design choices (ARCH 06):** D3
**Exit gate:** a quota stops an over-limit query before it runs; a running query is cancelled; two sources merge by time
**Depends on:** 0.11
**Requirements:** R-W1 R-W2 R-W3 R-Y1 R-Y2

## Scope

- Running queries and cancel
- Work groups and quotas per role
- Query statistics
- Several GreptimeDB sources with fan-out and merge

## Acceptance criteria

| AC | Reqs | Statement | Tests (≥2 each) |
|---|---|---|---|
| AC0.12.1 | R-W1 | Running queries come from GreptimeDB's process list with attribution; cancel works for permitted roles and is audited | `ac_0_12_1_process_list_attribution`, `ac_0_12_1_cancel_requires_permission`, `ac_0_12_1_cancel_live` |
| AC0.12.2 | R-W2 | Quotas for concurrency, timeout, rows and window are enforced before execution; the limit that blocked is named in the error | `ac_0_12_2_quota_concurrency`, `ac_0_12_2_quota_window_rows`, `ac_0_12_2_quota_error_names_limit` |
| AC0.12.3 | R-W3 | Statistics rank slowest and most frequent query tags per user and org; admin only | `ac_0_12_3_stats_slowest`, `ac_0_12_3_stats_admin_only` |
| AC0.12.4 | R-Y1 | List and search endpoints fan out to every permitted source, merge by time, and return per-source errors without failing the whole request | `ac_0_12_4_fanout_merge_order`, `ac_0_12_4_partial_failure_reported`, `ac_0_12_4_federation_live` |
| AC0.12.5 | R-Y2 | Source selector respects RBAC; per-source health is reported; a source can be disabled without restart | `ac_0_12_5_source_rbac`, `ac_0_12_5_source_health`, `ac_0_12_5_source_disable` |

## Notes

Built: see ADR 0013. Verified live on GreptimeDB v1.3.0 (`ac_0_12_1_cancel_live`: process list match and a real `KILL`; `ac_0_12_4_federation_live`: a twin source returns exactly twice the rows, newest first). Browser pass: Administration (Queries, Work groups), Platform (Sources), Logs source picker (`images/ui_queries.png`, `ui_workgroups.png`, `ui_sources.png`, `ui_logs_sources.png`).

Limits: statistics are per process; attribution is by statement text; quotas are per org and role; federation covers logs search and the trace list; the rows limit is enforced after reading at most one row more than the limit; two separate clusters were not available, so a second source was the same server.
