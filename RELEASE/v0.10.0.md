# RELEASE v0.10.0: Pipelines, functions, enrichment, redaction

**Status:** planned
**Design choices (ARCH 06):** D2
**Exit gate:** a pipeline is created, dry-run and listed; a CSV enrichment join works; redaction hides a field for a role
**Depends on:** 0.9
**Requirements:** R-F4 R-N1 R-N2 R-N3 R-N4

## Scope

- Pipelines manager over GreptimeDB's pipeline API with dry-run
- Saved SQL functions
- Enrichment tables from CSV
- Redaction rules per field and role

## Notes

GreptimeDB pipelines are YAML-configured, not VRL scripts; this is a documented difference. Cipher-key field encryption is not implemented (redaction only).
