# RELEASE v0.3.0: State, saved views and stream health

**Status:** planned
**Design choices (ARCH 06):** D3 D6
**Exit gate:** `grepui migrate` idempotent on the pinned DB; saved views and history survive restart; data-health page works
**Depends on:** 0.2
**Requirements:** R-F4 R-I2 R-S1 R-S2 R-S3 R-S4 R-S5

## Scope

- `grepui migrate` and the `grepui_*` metadata tables (schema version table, views, history)
- Saved views and query history
- Stream details page; ingest health (rows per minute, freshness, last seen)
