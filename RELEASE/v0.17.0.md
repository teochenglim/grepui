# RELEASE v0.17.0: Hardening

**Status:** ready
**Design choices (ARCH 06):** all
**Exit gate:** API shapes frozen by golden files; the supported GreptimeDB version (v1.3.0 only) is stated and checked at start-up and the live suite is green on it; security review recorded
**Depends on:** 0.16
**Requirements:** R-C2 R-F4 R-Q1 R-O3 R-O4

## Scope

- Golden files for every response shape
- Supported GreptimeDB version: **v1.3.0 only** (owner decision). A start-up check warns when the database reports an older version. A run of the live suite on v1.2.1 (2026-10-31) failed 11 of 44 tests (trace v2 tables for the LLM views and analytics, the Connect v2 headers, RUM), so older versions are not supported
- Security review: read-only claim, write allowlist, RBAC route table, SQL mode, redaction
- Browser security headers on every response (CSP and friends), and SQL mode never reads grepui's own tables (both found by the review)

## Notes

One new requirement, R-O4 (browser security headers). The API-shape freeze that was planned for 1.0.0 happens here, with the golden files; 1.0.0 is the evidence release (vision only, RELEASE/v1.0.0.md).

## Built

See ADR 0018 and `docs/security-review-0.17.0.md`. Golden files: `tests/golden/response_shapes.json` (148 routes: 84 answer 200, the rest 4xx errors whose shape is also frozen, plus 7 writes) and `tests/golden/routes.txt`; both gates were shown to fail when a shape key and a permission were altered, then restored. Security review: SQL mode probed with 56 hand-written bypass attempts; finding 1 (`grepui_*` tables readable when an org's database was the metadata database) and finding 2 (no browser security headers) fixed and tested; accepted risks listed. The supported GreptimeDB is v1.3.0 and newer only (owner decision); a run of the live suite on v1.2.1 failed 11 of 44 tests (ac_0_13_2_rum_live, ac_0_14_1_both_layouts_live, ac_0_14_2_connect_headers_accepted_live, ac_0_15_4_graph_matches_batch_live, ac_0_16_1/2/3 live tests: trace v2 tables and RUM). Browser pass (admin, playground): ten pages, the trace page, and a dashboard with markdown and HTML text panels inside their sandboxed iframes under the new policy, no console or policy errors.

Limits: the CSP keeps `'unsafe-inline'` for styles and allows `https:` images (text panels); the golden shapes freeze structure, not values; a start-up version warning does not stop an older database from being used; a 10 M-row load test was started and set aside by the owner (not part of this release).
