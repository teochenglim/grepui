# RELEASE v0.18.0: Documentation (User Guide, Technical Guide, README with screenshots)

**Status:** ready
**Design choices (ARCH 06):** none (documentation only)
**Exit gate:** a new user can start grepui from the README alone and find every page in the User Guide; an operator can find every flag, environment variable, command and documented route in the Technical Guide; nothing the docs name is missing from the repository
**Depends on:** 0.17
**Requirements:** R-D4

Why one release: documentation only. No code path, route, schema or flag changes; the only Rust added is a test file that keeps the documents true.

## Scope

- `docs/guide/user-guide.adoc` (AsciiDoc, for the people who use the pages): sign-in and roles, the top bar, Streams, Data health, Logs (filter syntax, SQL mode, saved views, export, several sources), Traces (waterfall, flame graph), Services, service map and catalog, Metrics, Dashboards (variables, public links, TV mode), Alerts, LLM observability (trace views, steps, agent graph, analytics, sessions, prices, who reads prompts), RUM, Pipelines, Functions, Enrichment, Redaction, Rollups and retention, Reports, Administration and Platform, Connect, troubleshooting; 45 screenshots from `images/`
- `docs/guide/technical-guide.adoc` (for operators): what grepui is made of, install by demo, image, binary or source, first start step by step, the default org, every flag with its environment variable and default, commands, orgs and roles, API tokens, audit, sending data, TLS and replicas, `/metrics`, upgrade, limits, the security model, the HTTP API (a table of routes, and the golden files), troubleshooting
- `README.md` rewritten for a first-time reader: what it does, a two-minute try-it, a tour with 11 screenshots, using your own data, links to the guides, a short safety section, the main settings, develop, status
- `docs/guide/README.md` as an index
- `tests/ac_docs.rs`: the documents are checked against the product

## Notes

AsciiDoc was chosen because GitHub renders it and `asciidoctor` can produce HTML or PDF without any Node or build step in the product. Both guides convert with zero warnings from Asciidoctor.js 3.0.4. The guides are hand-written; the test keeps them from drifting on facts that can be checked (flags, variables, commands, routes, pages, images, links). It cannot check prose.

Screenshots are the ones taken during each release's browser pass; they are not regenerated by this release and may differ slightly from the current CSS.

## Built

Verified: `make check` (nine new tests; the flag test fails when a flag is removed from the guide, tried by hand), and both guides rendered with Asciidoctor.js (0 warnings, 45 and 2 images, 5 and 11 tables).

Limits: the README and guides were not viewed on GitHub itself, only converted locally; the HTML was not opened in a browser; PDF output was not produced; the guides state what the product does as far as the code and the earlier browser passes show, and a page's behaviour that was never exercised in a browser (see `RELEASE.md` section 5) is described from the code; the User Guide has no screenshot for several smaller pages (Functions, the alert-history list) because none exists in `images/`.
