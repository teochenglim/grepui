# RELEASE v1.0.0: Better than the reference platform, shown by evidence

**Status:** planned (vision only: no scope, ACs or tests yet)
**Design choices (ARCH 06):** all
**Exit gate:** every row of `ARCH/07_parity_matrix.md` is `done`, `better` or an explicit, argued non-goal; every comparison grepui publishes is a reproducible test or measurement in this repository; every ADR still holds against what was built
**Depends on:** 0.17
**Requirements:** none yet (the 1.0.0 scope is written when this release is planned)

## Vision

grepui 1.0.0 is the release where the claim in the README, "parity with the reference platform plus its enterprise tier, in one Apache-2.0 binary on top of GreptimeDB", stops being a plan and becomes something a stranger can check. The target is a product that, for a team that runs GreptimeDB, is the better observability UI than the reference platform and the other products people compare it with (Grafana, Kibana, Jaeger, Phoenix and the like), judged on the work a team does, not on a feature count.

"Better" is only used where it can be shown. The rule for 1.0.0:

1. **No claim without evidence in the repo.** A statement that grepui is faster, safer, simpler or more complete than another product is a row in `ARCH/07` that points to a test, a benchmark script with its recorded output, or a link to the other product's own documentation read on a stated date. Anything else is written as "not compared".
2. **The gap list reaches zero.** Each `gap` row in `ARCH/07` (live tail, log patterns, insights and root-cause analysis, SLOs, annotation sources, drilldowns, and the rest) is built, or closed as a non-goal with an ADR that says why a team would not miss it.
3. **Where grepui should be better, it is measured to be.**
   - *Correlation:* one click between logs, traces, services, metrics and LLM spans, with the filter and time range carried across; counted as clicks and requests for a fixed investigation script.
   - *Cost and operations:* one dependency (GreptimeDB), one static binary, no second datastore, replicas that coordinate through the database; recorded as resources used and moving parts on the same seeded data.
   - *Long ranges:* the rollup planner and result cache against raw queries on the same data; recorded as latency at 10 M and larger.
   - *Safety:* typed API, parser-validated SQL mode, write allowlist, deny-by-default route table, redaction on every response and prompt masking; backed by the invariants tests and a recorded security review, repeated before 1.0.0.
   - *LLM observability:* OpenInference and `gen_ai.*` read natively, with transcripts, evaluations, an agent graph, analytics and alerts, in the open binary; checked against the same trace set sent to other products where they can be run locally.
   - *Enterprise tier in the open binary:* access control, SSO, audit, work groups, federation and reports without a paid edition.
4. **The decisions hold.** Every ADR (0001 onward) is re-read against the code and tests: it is still true, or it is amended or superseded with a new ADR. 1.0.0 does not ship with a decision record that describes something that is no longer there.
5. **A stranger can reproduce it.** `make demo` and `make playground` bring up the data the comparisons use; the benchmark and comparison scripts are in the repo with the versions of the other products they ran against.

## What 1.0.0 is not

It is not a promise to copy every feature of every competitor, a rewrite, or a new ingest path: grepui reads GreptimeDB and does not ingest (ARCH 06 non-goals). It does not publish a "faster than X" number it did not measure on the same data and the same machine, and it does not name a competitor's behaviour it has not seen run or read in their documentation.

## Open decisions for the owner (before this release is planned)

- Which products are in the comparison set, and which can be run locally for a fair test.
- Which `gap` rows are worth building and which are written off.
- The scale and hardware the benchmarks are stated for.
- Whether 1.0.0 also freezes the API (planned for 0.17.0 with the golden files) or keeps that for a later minor.
